Nobify has three parts: a small server that collects detections, a dashboard (this site), and a desktop companion that shows tray notifications. The ESP32-S3 sensor node uploads over WiFi and updates itself over-the-air. No source checkout required — download, flash, done.

1 · Desktop companion

tray notifications + snooze

Double-click installers — no Node, no build tools. Pick your platform:

🪟 Windows Download .exe
🍎 macOS Download
🐧 Linux Download

Or install & register run-at-login with one line:

irm https://OWNER.github.io/REPO/install.ps1 | iex
curl -fsSL https://OWNER.github.io/REPO/install.sh | bash

Then point it at your server: nobify --server https://your-server (the tray menu can change it too).

2 · Flash your ESP32-S3

right here in the browser

Plug the sensor into USB and flash the latest factory firmware directly from this page — no PlatformIO, no esptool, no source. Works in Chrome/Edge over WebSerial.

Open this page in Chrome or Edge on desktop to flash over USB. WebSerial needs an HTTPS page (this one) and a permitted USB port. Open in Chrome or Edge on desktop to flash over USB.
  1. Hold BOOT, tap RST, release BOOT to enter download mode (native-USB S3 boards need this).
  2. Click Flash above and pick the USB JTAG/serial port.
  3. Right after flashing, this page asks for your WiFi network (Improv-WiFi over USB) and sends it to the device — no secrets are baked into the public image.
  4. Then open http://<device-ip>/ (the browser offers the link) to point the sensor at your server URL.

After the first flash, devices poll /api/firmware/manifest and self-update over-the-air — you never have to plug in again.

3 · Server (local or hosted)

Node ≥ 22.5 · single file

One self-contained file — no clone, no npm install, no node_modules. Download it and run:

📦 nobify-server.mjs Download server

…or fetch & start in one line:

irm https://github.com/OWNER/REPO/releases/latest/download/nobify-server.mjs -OutFile nobify-server.mjs; node nobify-server.mjs
curl -fsSL https://github.com/OWNER/REPO/releases/latest/download/nobify-server.mjs -o nobify-server.mjs && node nobify-server.mjs

Starts on http://localhost:8787. It creates a data/ folder next to itself for the database.

  1. Expose it (so the ESP32 and this dashboard can reach it). For a quick tunnel: 
    npx localtunnel --port 8787
# or: cloudflared tunnel --url http://localhost:8787
  2. Point this dashboard at it: open the dashboard, click ⚙ Settings, and paste your server URL. (Hosted on GitHub Pages, this page can't guess your local server.)
