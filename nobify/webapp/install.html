Nobify has three parts: a small server that collects detections, a dashboard (this site), and a desktop companion that shows tray notifications. The ESP32-S3 sensor node uploads over WiFi and updates itself over-the-air. Grab what you need below.

1 · Desktop companion

tray notifications + snooze

Double-click installers (no Node required). Pick your platform:

🪟 Windows Download .exe
🍎 macOS Download
🐧 Linux Download

Prefer Node? zero-dep friendly 

git clone https://github.com/OWNER/REPO.git
cd nobify/companion
npm install            # optional — adds tray icon + rich toasts
npm start -- --server http://localhost:8787

2 · Server (local or hosted)

Node ≥ 22.5 · zero native deps
  1. Install & run 
    cd nobify/server
npm install
npm run seed     # optional demo data
npm start        # http://localhost:8787
  2. Expose it (so the ESP32 and this dashboard can reach it). For a quick tunnel: 
    npx localtunnel --port 8787
# or: cloudflared tunnel --url http://localhost:8787
  3. Point this dashboard at it: open the dashboard, click ⚙ Settings, and paste your server URL. (Hosted on GitHub Pages, this page can't guess your local server.)

3 · ESP32-S3 firmware + OTA

PlatformIO

Flash the first time (USB)

# 1. edit nobify/firmware/nobify.config.yaml
#    (wifi, server.url, pins)
cd nobify/server && npm run gen:firmware
cd ../firmware && pio run -t upload
pio device monitor

Update later (over-the-air)

Devices poll /api/firmware/manifest and self-update. Publish a build:

# drop the built image + manifest on the server
cp .pio/build/*/firmware.bin \
   ../server/firmware/nobify-fw-1.1.0.bin
# server serves it; ESP32 upgrades automatically

Local push OTA also works: pio run -t upload --upload-port <device-ip>
