# IONITY brand mark — "AI" monogram (2026)

All assets here are generated from the IONITY **AI** monogram (`marks/ai-mark.png`),
the canonical brand icon used on ionity.co.za / ionity.today.

- **favicon/** — `favicon.ico` (64px), `favicon-32.png`, `favicon-64.png`. Blue AI on a white rounded tile.
- **pwa/** — `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` (180). Blue AI on a white rounded tile.
- **social/**
  - `social-card.png` — 1200×630 Open Graph / Twitter link-preview card (white AI on the dark brand gradient + wordmark + tagline).
  - `social-avatar.png` — 512×512 square profile picture for LinkedIn / GitHub / Gravatar / X, etc. (blue AI on white tile).
- **marks/** — transparent source monograms: `ai-mark.png` (blue), `ai-mark-white.png` (white).

Regenerated by `_build/gen-icons.mjs` in the website repo
(`Ionity-Global/Ionity-offical-website-2026-remaster-Q3-plus`) — run `npm run icons`.
